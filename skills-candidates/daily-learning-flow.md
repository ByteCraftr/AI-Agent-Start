# Codex Skill 候选：每日 Agent 学习流程

这个文件用于记录未来可以抽成 Codex skill 的稳定流程。先不要急着实现 skill，等这个流程跑 3-5 次后，再决定是否抽象。

## 触发语

```text
今天领取 CHECKLIST 里的下一个任务，带我完成。
```

## 预期行为

Codex 应该：

1. 读取 `CHECKLIST.md`，找到第一个未完成任务。
2. 解释今天要学的核心概念。
3. 给出与 Parenting Copilot 相关的实现任务。
4. 带用户完成代码或文档修改。
5. 运行必要验证。
6. 更新任务状态和周复盘。
7. 给出下一次学习入口。

## 抽成 skill 前的观察点

- 每天任务格式是否稳定。
- 是否需要自动更新 checklist。
- 是否需要生成代码模板。
- 是否需要固定复盘问题。
- 是否需要把学习笔记自动归档到 `notes/`。
