# 00: Agent 基础概念

## 先建立一个判断

Agent 不是“更会聊天的模型”，而是一个围绕目标运行的系统。

一个最小 Agent 通常包含：

- 输入理解：用户到底想解决什么问题。
- 状态管理：当前知道什么，还缺什么。
- 推理决策：下一步应该回答、追问、查资料，还是调用工具。
- 工具行动：访问数据库、搜索、生成计划、写文件等。
- 结果校验：输出是否符合格式、安全边界和业务目标。
- 记忆更新：哪些信息值得进入长期上下文。

## Parenting Copilot 的 Agent 视角

家长问：

```text
孩子 7 岁，最近不愿意写作业，一写就发脾气，我也很容易着急，怎么办？
```

普通聊天机器人会直接给建议。

Agent 应该先做这些判断：

- 这是学习问题、情绪问题，还是亲子沟通问题？
- 信息是否足够？
- 有没有高风险信号？
- 是否需要读取孩子历史画像？
- 是否需要基于教育知识库查资料？
- 输出应该是一次建议，还是包含后续跟踪计划？

## 本项目的核心学习方法

每个概念都要落到三个层面：

- 概念：它解决什么问题？
- 代码：如何实现一个最小版本？
- 产品：它如何改善 Parenting Copilot？
