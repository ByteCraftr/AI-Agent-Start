# 项目背景

本文件记录 Parenting Copilot / 亲子教育 Agent 的长期目标和学习主线。

## 长期目标

本项目不是为了零散学习 AI 工具，而是为了形成一套完整能力：

- 理解 AI Agent 的底层机制。
- 能从 0 到 1 设计一个 Agent 系统。
- 能用代码实现可运行的 Agent 原型。
- 能围绕 Parenting Copilot 形成产品、架构、评估和安全设计。
- 最终形成可展示的作品集、求职材料或创业产品雏形。

## 产品主线

主项目：**Parenting Copilot / 亲子教育 Agent**。

所有学习都尽量回到这个产品主线，而不是只做孤立 demo。

每个知识点都按三层理解：

```text
概念层：它解决什么问题？
工程层：如何用代码实现？
产品层：它如何改善 Parenting Copilot？
```

## 安全边界

Parenting Copilot 只能提供父母监督下的低风险建议：

- 不做诊断。
- 不替代医生、心理咨询师、学校老师或其他专业人员。
- 对高风险或紧急情况要建议寻求专业帮助。
- 对教育、儿童、安全相关内容保持明确边界。
